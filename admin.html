Langkah Cepat Supabase SQL:
1. Buka SQL Editor di dashboard Supabase kamu.
2. Salin seluruh isi file supabase-schema.sql di proyek ini.
3. Klik tombol Run untuk membuat tabel & memasukkan 52 produk otentik secara instan!
